# Project: Gen AI Learning Path

Open-source Generative AI projects by difficulty. Works locally and in Databricks.

| Level | Local scripts | Databricks notebooks |
|-------|---------------|----------------------|
| Basic | [`basic/`](./basic/) | [`notebooks/basic/`](./notebooks/basic/) |
| Intermediate | [`intermediate/`](./intermediate/) | [`notebooks/intermediate/`](./notebooks/intermediate/) |
| Advanced | [`advanced/`](./advanced/) | [`notebooks/advanced/`](./notebooks/advanced/) |

## Local quick start

```bash
cd projects/gen-ai/basic
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python 01_hello_llm.py
```

## Databricks

Open `projects/gen-ai/notebooks/basic/01_hello_llm` from the Git folder and run on an ML cluster.
