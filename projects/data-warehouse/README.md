# Project: NovaMart Retail Data Warehouse

Build a complete retail data warehouse on Databricks using **medallion architecture** and a **star schema**.

## Contents

| Path | Purpose |
|------|---------|
| [`notebooks/`](./notebooks/) | Databricks notebooks `00` → `09` |
| [`jobs/`](./jobs/) | Databricks Job JSON + setup guide |

3. `notebooks/02_bronze_ingestion`
4. `notebooks/03_silver_transform`
