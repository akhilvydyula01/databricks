## Quick start in Databricks

1. **Repos / Git folders → Add Repo** → `https://github.com/akhilvydyula01/databricks`
2. **Pull** latest
3. Open a project notebook, for example:
   - `projects/data-warehouse/notebooks/00_architecture_overview`
   - `projects/gen-ai/notebooks/basic/01_hello_llm`
4. Attach a cluster → Run all
